# 项目长期记忆 · 兰途 LanTu

> 本文件是项目的"大脑"。每次在 WorkBuddy 打开这个项目，AI 都会读它，从而记得项目背景、约定和进度，无需重新交代。请保持更新。

## 一、项目是什么
家庭 AI 兰途旅行原型（品牌名"兰途 / LanTu"）。手机端竖屏。
双重目的：①实用旅行规划工具（每次出行=一个 project）②让 AI 新手（太太）在真实项目里上手 AI 协作。

## 二、协作模式（重要）
- 双人协作：陈宇清（主创，负责架构/开发）+ 太太（协作者，肯学的半新手，负责内容/迭代）
- 协作中枢：GitHub 私有仓库。两人各自在自己电脑的 WorkBuddy 里打开本项目（同一仓库的两份克隆），用 git push/pull 同步。
- 太太用法：以自然语言指挥 WorkBuddy 改内容 + 让 AI 代执行 git 同步，尽量不手敲 Git 命令。
- 分工避免冲突：太太主改内容/文案（docs、原型文字），陈宇清主改结构/逻辑，尽量不同时改同一文件。

## 三、设计约定（AI 迭代时必守，详见 docs/设计规范.md）
- 青绿 #17A398 主色 × 珊瑚 #FF6F52 仅做 CTA/点亮地图，每屏 ≤1 珊瑚 CTA
- AI 内容用微紫渐变卡 + ✨徽标（新手识别标志）
- 三分类色：旅行蓝 #2E8BD6 / 徒步绿 #5B9E3F / 度假橙 #F2994A
- 暖米白背景 #FBF9F6，禁纯白/纯黑/冷灰；圆角卡20/按钮14；措辞生活化
