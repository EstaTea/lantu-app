# 旅记 TripDiary · 需求摘要

> 产品需求与信息架构，AI 迭代功能时的依据。

## 一、产品定位
家庭 AI 旅行计划小程序（手机竖屏）。双重目的：
1. 实用旅行规划工具 —— 每次出行作为一个"项目"来规划、记录、复盘
2. 让 AI 新手（太太）在真实项目里上手 AI 工具协作

## 二、信息架构（底部 4 Tab）
1. 我的行程（首页）—— 项目列表，进行中/已完成分组
2. 点亮地图 —— 国内省份 / 世界地图双模式
3. 新建 + —— 中央凸起珊瑚按钮
4. 我的 —— 个人/协作/设置

**Project 详情页是全应用枢纽**，所有录入、AI、协作、归档从此发散。

## 三、核心功能清单
- [x] 每次出行 = 一个 project
- [x] 录入：前期准备 / 行程 / 住宿
- [x] AI 建议 / 路线规划 / 高光时刻
- [x] 生成行程 form 打印备份
- [x] 计划预算 vs 实际费用
- [x] 增加共同编辑人（协作）
- [x] project 分类（旅行/徒步/度假）字段不同
- [x] 归档已完成 → 点亮地图

## 四、分类差异化字段（产品亮点）
共享字段：标题、日期、目的地、封面、协作人、预算。差异在内容模块：

### 🧳 旅行类（观光）
景点清单（必去/备选+营业时间）、城际交通、行程日排、美食清单、住宿

### 🥾 徒步类（户外）
路线（起终点/里程/海拔爬升/用时）、难度⭐1-5、装备勾选清单、补给点/营地、安全信息

### 🏖️ 度假类（放松）
住宿为核心（房型/含餐/设施/退改）、放松活动清单、每日松散节奏、酒店餐饮

## 五、AI 能力落点
1. **AI 旅行建议** —— 详情页概览顶部渐变卡，气泡条目 + "采纳"按钮
2. **AI 路线规划** —— 行程 Tab "✨一键生成路线"按钮
3. **AI 高光时刻** —— 归档时自动生成高光卡（精选图+文案+数据），地图点亮页展示

## 六、给新手降门槛的设计
大图标选分类 / AI 主动开口引导 / 协作可见痕迹 / 勾选优先于输入 / 空状态友好 / 采纳式交互 / 生活化措辞（"这次旅行""一起记录"）
