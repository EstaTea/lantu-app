## 关键成功因素

### 1. 全程用 AI 写代码

**在 WorkBuddy 里这样说：**
- "把这段原型 HTML 转成小程序 WXML 和 WXSS"
- "帮我写一个云函数，查询 trips 表的所有数据"
- "写一个表单页面，包含标题、日期、目的地三个字段"
- "写一个上传照片到云存储的函数"

**AI 能做 80%，你只需要：**
- 复制 AI 的代码到开发者工具
- 改改字段名、调调样式
- 遇到报错截图给 AI，让它修

### 2. 用微信云开发（零后端）

**优势：**
- 不需要租服务器
- 不需要写后端 API
- 数据库、存储、函数都是现成的

**5 分钟上手：**
```javascript
// 查询数据
const db = wx.cloud.database()
db.collection('trips').get().then(res => {
  console.log(res.data) // 所有旅程
})

// 新增数据
db.collection('trips').add({
  data: { title: '尼泊尔 ACT', startDate: '2026-10-05' }
})
```

### 3. 减少决策时间

**遇到问题用最简单方案：**
- 样式不完美？先用系统默认
- 动画卡顿？先删掉动画
- 功能太复杂？先砍掉

**记住：能用 > 完美**
