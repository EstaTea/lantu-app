# 旅记 TripDiary · 设计规范（Design Tokens）

> 本文件记录项目的视觉设计约定，AI 迭代原型时必须遵守，保证风格一致。

## 一、设计系统基因
- **基底**：Airbnb 基因（大图卡 + 克制留白 + 圆润无衬线 + 强信任感）
- **定制偏移**：主品牌色由珊瑚改为青绿/蓝绿系（度假海岛感），珊瑚下沉为 CTA/高光色

## 二、色彩令牌（核心）
| 用途 | 变量 | 色值 |
|------|------|------|
| 主品牌色（青绿） | `--c-primary-500` | `#17A398` |
| CTA / 点亮地图（珊瑚） | `--c-coral-500` | `#FF6F52` |
| 高光暖阳 | `--c-sun-400` | `#FFC65C` |
| AI 内容底色（微紫） | — | `#F1F0FF` |
| AI 徽标紫 | — | `#7C6CF0` |
| AI 渐变 | — | `135deg 青绿→柔紫→珊瑚` |
| 旅行类主题色 | — | `#2E8BD6`（蓝） |
| 徒步类主题色 | — | `#5B9E3F`（绿） |
| 度假类主题色 | — | `#F2994A`（橙） |
| 背景（暖米白） | — | `#FBF9F6` |
| 文字（暖黑） | — | `#2A2622` |
| 地图未点亮 | — | `#D7D0C6` |
| 地图已点亮 | — | 珊瑚 `#FF6F52` + 暖阳双层光晕 |

## 三、排版 / 间距 / 圆角
- 字体：Nunito + PingFang SC（圆润无衬线栈）
- 字号：7 级，28 → 11px
- 间距：8pt 系统
- 圆角：卡片 20px / 按钮 14px / chip 全圆 / 图片 16px
- 阴影：暖调柔和，`rgba(120,100,80,...)`，禁纯黑硬边

## 四、5 条 Anti-Slop 设计纪律（不可违背）
1. 暖米白背景 + 暖调阴影，禁纯白/纯黑/冷灰
2. 青绿 × 珊瑚严格分工：青绿做导航/进度/AI路径，珊瑚**只做** CTA 和点亮地图，每屏 ≤1 个珊瑚 CTA
3. AI 内容专属微紫渐变卡 + ✨徽标，与全站"不同族"，让新手一眼识别"这是AI给的、可采纳"
4. 大图卡 + 分类色竖条 + 底部渐变遮罩
5. 点亮地图珊瑚+暖阳双层光晕 + 弹跳微交互 —— 全 App 唯一情感爆发点，保持仪式感
