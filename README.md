# 兰途 LanTu 🧳

> 家庭 AI 兰途旅行 —— 每一次出行，都是一个值得记录的项目。

一个家庭协作项目：既是实用的旅行规划工具，也是我们俩一起上手 AI 工具的练手场。

## ✨ 核心功能
- 📁 每次出行 = 一个项目，分类管理（旅行 / 徒步 / 度假，字段各不同）
- 🤖 AI 自动给旅行建议、路线规划、旅程高光时刻
- 📝 录入前期准备、行程、住宿
- 💰 计划预算 vs 实际费用
- 🖨️ 生成行程单打印备份
- 👫 添加共同编辑人，一起规划
- 🗺️ 行程结束归档，点亮属于我们的地图

## 🚀 怎么看原型
双击 `prototype/index.html`，用 Chrome / Safari 打开即可。首次建议联网（显示旅行封面照片）。

## 👫 怎么一起协作
1. 本项目托管在 GitHub 私有仓库
2. 两人各自在自己电脑的 WorkBuddy 里打开本项目
3. 改完让 AI 帮忙 `git push`；开工前让 AI 帮忙 `git pull`
4. 新手请先读 `docs/太太的AI协作上手指南.md`
